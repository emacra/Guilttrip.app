# Guilttrip.app

Guilttrip.app is a Flask-based planner app for tracking tasks, deadlines, and writing reflections.

## Live app

This is the Render URL: https://guilttrip-app-82rc.onrender.com

## Run locally

Run `python app.py` and open http://127.0.0.1:5001 on the same computer running the app.
